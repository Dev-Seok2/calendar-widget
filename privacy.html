개인정보처리방침 Privacy Policy — 캘린더 위젯 (Calendar Widget)

시행일 / Effective date: 2026-11-27

1. 사용하는 Google 데이터 / Google data the app accesses

사용자가 직접 허용한 범위 안에서만 다음 데이터에 접근합니다.

  • Google Calendar (calendar): 일정을 위젯에 표시하고, 사용자가 위젯에서 추가·수정·삭제한 일정을 저장합니다.
  • Google Tasks (tasks): 할 일을 표시하고, 완료 체크·추가·수정을 반영합니다.
  • Gmail 읽기 전용 (gmail.readonly, 사용자가 "메일에서 일정 제안"을 켰을 때만): 최근 메일의 제목·본문에서 날짜를 찾아 일정 후보를 제안합니다. 메일을 보내거나 수정·삭제하지 않습니다.

The app only accesses data within the permissions you grant: Google Calendar (show, add, edit, delete your events), Google Tasks (show and update your tasks) and, only if you turn on "suggest events from mail", Gmail read-only (find dates in recent mail to suggest events; it never sends, changes or deletes mail).

2. 저장과 전송 / Storage and sharing

  • 모든 처리는 사용자의 PC에서만 이루어집니다. 로그인 토큰, 설정, 마지막으로 불러온 일정의 사본은 사용자 PC의 %APPDATA%\CalendarWidget 폴더에만 저장됩니다.
  • 이 앱에는 개발자 서버가 없습니다. Google 사용자 데이터를 개발자나 제3자에게 전송·판매·공유하지 않으며, 광고나 사용자 분석에 쓰지 않습니다.
  • All processing happens on your PC. Sign-in tokens, settings and a cached copy of recently loaded events are stored only in %APPDATA%\CalendarWidget on your PC. The app has no server: Google user data is never sent, sold or shared with the developer or any third party, and is not used for advertising or analytics.

3. Google API 서비스 사용자 데이터 정책 / Limited Use

이 앱이 Google API로부터 받은 정보의 사용 및 전송은 Google API Services User Data Policy의 제한적 사용(Limited Use) 요구사항을 포함하여 해당 정책을 준수합니다.

The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

4. 데이터 삭제와 연결 해제 / Deleting data and revoking access

  • 위젯을 지우고 %APPDATA%\CalendarWidget 폴더를 삭제하면 PC에 저장된 데이터가 모두 지워집니다.
  • 앱의 접근 권한은 Google 계정 → 타사 앱 및 서비스에서 언제든 취소할 수 있습니다.
  • Uninstall the widget and delete the %APPDATA%\CalendarWidget folder to remove all stored data. You can revoke the app's access at any time at your Google Account permissions page.
