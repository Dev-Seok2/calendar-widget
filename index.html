설치 (처음 한 번, 3분)

  1. 위 다운로드를 눌러 받은 CalendarWidget.zip을 마우스 오른쪽 → 압축 풀기 (문서 폴더 등)
  2. 풀린 폴더의 CalendarWidget 폴더 안 CalendarWidget.exe 더블클릭
    파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행 (개인이 만든 프로그램이라 뜨는 안내예요)
  3. [구글로 연결] → 내 구글 계정 선택 → "확인하지 않은 앱"이 나오면 고급 → 이동 → 체크박스 모두 체크 → 계속

처음 실행하면 바탕화면과 시작 메뉴에 "캘린더 위젯" 바로가기가 저절로 생겨요. exe 파일만 따로 복사하면 실행되지 않으니 폴더째로 두세요.

업데이트는 다시 받을 필요 없어요. 새 버전이 나오면 위젯에 알림이 뜨고 [업데이트] 버튼 한 번이면 됩니다.
