핵심 기능

📅 바탕화면 달력구글 캘린더 일정과 할 일(Google Tasks)을 월간·주간으로. 끌어서 날짜 옮기기, 바뀐 내용은 휴대폰에도 그대로.
⚡ 빠른 추가"내일 3시 회의 @3층 회의실"처럼 한 줄로 쓰면 날짜·시간·장소가 알아서 들어가요.
📨 Outlook 일정도 함께회사 Outlook·Teams 일정을 링크로 불러와 구글 일정과 한 달력에. 캘린더마다 색도 내 마음대로.
▶ 회의 바로 참여Teams·Zoom·Google Meet 링크가 있는 일정에 [참여] 버튼. 시작 알림을 눌러도 바로 접속.새 기능
☀ 아침 브리핑 · 알림매일 아침 오늘 일정·마감 요약, 일정 시작 전 알림. 시각은 설정에서.새 기능
📌 D-day · 마감다가오는 마감을 D-2, D-day로 표시하고, 휴가·프로젝트 같은 날은 D-day로 고정.새 기능
🖥 방해 안 되는 위젯바탕화면에 고정, 투명도·다크 테마, 작게 보는 컴팩트 모드. Ctrl+Alt+K로 숨기기/불러오기.
💸 월급 카운터 (재미로)오늘 번 돈이 출근부터 퇴근까지 차올라요. 금액은 마우스를 올릴 때만 보여 회사에서도 안심.
📶 인터넷이 끊겨도저장된 일정을 계속 보여 주고, 끊긴 동안 바꾼 일정은 연결되면 자동으로 저장.새 기능
🔔 공지 감시보고 싶은 게시판 주소와 키워드를 넣으면 새 글이 올라올 때 알려 줘요.

설치 (처음 한 번, 3분)

  1. 위 다운로드를 눌러 받은 CalendarWidget.zip을 마우스 오른쪽 → 압축 풀기 (문서 폴더 등)
  2. 풀린 폴더의 CalendarWidget 폴더 안 CalendarWidget.exe 더블클릭
    파란 "Windows의 PC 보호" 창이 뜨면 추가 정보 → 실행 (개인이 만든 프로그램이라 뜨는 안내예요)
  3. [구글로 연결] → 내 구글 계정 선택 → "확인하지 않은 앱"이 나오면 고급 → 이동 → 체크박스 모두 체크 → 계속

처음 실행하면 바탕화면과 시작 메뉴에 "캘린더 위젯" 바로가기가 저절로 생겨요. exe 파일만 따로 복사하면 실행되지 않으니 폴더째로 두세요.

업데이트는 다시 받을 필요 없어요. 새 버전이 나오면 위젯에 알림이 뜨고 [업데이트] 버튼 한 번이면 됩니다.
